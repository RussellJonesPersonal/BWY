A narrow text block

Using a narrow text block can make the content easier to read on wide screens. The eye follows narrow text more easlily than long text that takes up the entire width of the page.

I suggest we make all text in this template use the narrow content space (unless it sits next to a sidebar or other formatting that requires a wider text width).

For demonstration purposes, I've added a full width text area below, so you can see the difference.

I've added a divider below. These can be added between sections. If you add a standard HR within a section, it will just be a line, not styled as shown.

A wide text block

Using a wide text block makes it harder to read on large screens. It's harder for the eye to track a line of text that is very long, and the text can end up looking a bit "lost" and slightly off-putting. It doesn't feel easy to read, even before you begin.

I suggest we make all text in this template use the narrow content space (unless it sits next to a sidebar or other formatting that requires a wider text width).

For demonstration purposes, compare this to the narrow text passage above. (On smaller screens they look the same.)

This layout is 2 images side-by-side. The images are set to 5:4 ratio automatically, which ensures a good appearance at all screen resolutions. Reflow content across columns

This layout automatically reflows the text across two columns (on larger screens). It's ideal for sections where there is quite a lot of content, but want to avoid (a) a long passage using the narrow text style, and (b) a passage of wider text, which can become difficult to read.

The remainde of this is Latin text. Try resizing the screen to see how this behaves.

Note, it is normal (and unavoidable) for this layout to have "ragged" endings, with one column taller than another.
