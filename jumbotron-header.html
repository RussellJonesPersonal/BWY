An alternative header

Some pages may benefit from a large image at the top. As well as giving the page greater visual impact, this helps prevent the website from feeling too repetitive while still maintaining a coherent design system.

If this design element is used, we strongly recommend choosing high-quality, appropriate imagery. Poor-quality images are never ideal, but presenting them at this scale makes the problem much more noticeable. It can undermine the credibility of the website and make users less likely to engage with the page.

The image shown above was generated in around a minute using a free AI tool. Real photography is always preferable where suitable high-quality images are available. If they are not, AI-generated imagery can be a practical alternative, provided it is created specifically for the site: with plenty of space, calm colours and a positive, relevant visual story.

This design automatically darkens and mutes the background image so that the white heading and breadcrumb remain clear and legible.

The image is cropped to automatically fill the space. Choose images with a composition that still works if the top and bottom are cropped off.

If using this header, try not to use any other images within a single page view. Too many images would make the page look cluttered.
