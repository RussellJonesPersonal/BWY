This is a standard content page

The content shown on this page is to demonstrate standard text formatting options. This page template can be deployed across the site, and you can add and format your own content, including adding images, buttons, and text formatting.

Other page template examples will also be developed. Some will be for specific purposes, others will be general purpose. General purpose templates are intentionally simple, so they can be used for a wide variety of content purposes.

You can add images to this page. They will always display at 100% of the width of the content space.

Text can be made bold, italic, or underlined. For legibility reasons we recommend you don't combine these, as the results can be hard to read, particularly for people with reading difficulties such as dyslexia, or for partially-sighted people.

We recommend avoiding underlined text, as it can too easily be mistaken for a link.

You can also add button links, but we recommend only using those very sparingly, for important calls to action.

We strongly recommend using only 2-3 words in a button, so the text doesn't wrap when viewed on a phone.

Heading styles

You can use the following heading styles. We recommend using them to break up content, or to draw attention to content. Do not use them for length segments of text, such as paragraphs. Keep headings short and clear. Emphasise how the content they describe helps the user.

Note: This page looks like it has too much space around the headings, but you would never use headings in this way (one on top of another). In real-world usage, the spacing will make the page easier to read and feel more luxurious.

Note: Heading 1 style is preserved for the page title. This is because search engines look for Heading 1, and use it to understand the site navigation. Having more than one Heading 1 on a page would reduce SEO.
